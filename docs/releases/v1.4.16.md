# Lumon v1.4.16

## Dashboard settings

- Show Auto Delivery schedule, JQL, submission-policy and target-branch guidance
  in click-to-open tooltip bubbles beside their labels. Opening help does not
  shift the form. Preserve keyboard focus and Escape dismissal, close on outside
  clicks, and keep bubbles inside the viewport without panel clipping.
- Label and disable missing or invalid Workspaces in the Agent default-Workspace
  picker. Preserve an unavailable saved default until the user explicitly changes
  it; opening Settings does not rewrite Agent configuration.

## Auto Delivery

- Use `lumon/delivery-<Story-key>` for newly created isolated delivery branches.
  Update the packaged execution prompt and localized guidance together. Existing
  branches, delivery records and Workspace hook prompts are not renamed.

## Upgrade

Run `lumon update` after the Release is published, then restart the Dashboard to
load the new UI. The running Agent does not need restarting for these changes;
scheduled delivery invocations load the updated template on their next run.

Workspace settings, credentials, schedules and paused automation states remain
unchanged. Unregistering stale Workspaces is a separate, explicit local cleanup;
this release does not automatically remove registrations or profiles.
