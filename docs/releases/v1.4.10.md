# Lumon v1.4.10

## Agent

- Apply saved Codex model and reasoning effort settings when the next request
  starts, without restarting Agent or reconnecting Feishu.
- Keep active requests on their original execution settings. Queued turns and
  resumed conversations use the latest saved settings while retaining history.
- Report invalid configuration safely and allow the next request to recover
  after the configuration is corrected.
- Keep execution trace metadata aligned with the model and reasoning effort
  used by each request.

## Dashboard

- Replace the blanket restart warning with guidance that model and reasoning
  effort changes apply to the next request. Other connection and observability
  settings still require restarting Agent.
- Update the save confirmation and help text in English, Simplified Chinese,
  and Traditional Chinese.

## Upgrade

After the GitHub Release is published, run `lumon update`. Restart Agent once
to load this implementation and reload the Dashboard process to load the new
UI. Future model and reasoning effort saves do not require an Agent restart.
Workspace data, credentials, saved model preferences, and scheduled Scan,
Delivery, and Workflow jobs remain unchanged. Auto Scan and Auto Delivery
already load the saved global execution settings at the start of each run.
