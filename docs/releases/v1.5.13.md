# Lumon 1.5.13

- Add an Auto Scan Current progress panel matching Auto Delivery's animated stage bars, using the actual review, report and finalization phases without estimating a percentage.
- Update the active scan's elapsed timer every second and freeze it on completion. Keep partial, failed, loading and unavailable states distinct.
- Discover running scans while a manual start request is pending and prioritize them over newer historical entries. Poll visible pages every three seconds while active and every fifteen seconds while idle; prevent duplicate starts and allow read-only refresh.
- Use the shared success-green style for resolved issue tags while retaining their compact shape.
- Document the approved concise Traditional Chinese Jira Bug format: problem/impact, root cause/remediation and evidence/validation, followed by a compact traceability footer. Workspaces select this format through their own completion prompt; Jira is not enabled globally.
- Add progress, timer, localization and polling coverage, and update Dashboard documentation.

The MBPass Workspace's saved Jira completion prompt is updated separately to use the documented format for future newly created Bugs. Existing duplicate checks, active-sprint placement, labels, field defaults, read-back verification and receipts remain in effect. This release does not rewrite existing Jira cards, rerun scans or alter schedules.
