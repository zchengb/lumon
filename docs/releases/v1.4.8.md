# Lumon v1.4.8

## Dashboard

- Show the installed Codex CLI version and a compact update badge inside the
  Agent provider field only when a newer stable release is available. The model
  refresh button also refreshes the update check without changing the saved
  model, reasoning effort, or settings.
- Add read-only `GET /api/agent/codex-status`. Checks use the active Codex
  executable and official package metadata, with bounded timeouts and caching.
  Failed checks do not block model selection or show an incorrect update badge.
- Remove normal model descriptions and verbose CLI details from Settings;
  retain loading and failure guidance when needed. The provider field keeps
  consistent sizing and a single focus ring.
- Shorten the Webhook save button to **保存**, **儲存**, or **Save** according to
  the interface language. Saving behavior is unchanged.

## Upgrade

After the GitHub Release is published, run `lumon update`. Reload only the
Dashboard process and refresh its browser tab to load the new API and UI.
Workspace data, credentials, saved model preferences, and scheduled Scan and
Workflow jobs remain unchanged. Lumon does not upgrade Codex automatically;
model availability still depends on the local Codex version and account access.
