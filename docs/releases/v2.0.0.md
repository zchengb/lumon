# Lumon 2.0.0

- Search repositories accessible to the signed-in GitHub account, including
  repositories owned by the user, shared with the user, or available through an
  organization
- Apply the organization filter and paginate the matching results across the
  full account list for GitHub.com and GitHub Enterprise
- Report a repository fetch failure instead of showing incomplete search results

Search accepts repository or owner names. GitHub search qualifiers such as
`user:` are no longer supported. Accounts with many repositories may take longer
to search because Lumon reads multiple pages

After upgrading, restart an idle Dashboard to load the new search behavior
