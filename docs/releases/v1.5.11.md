# Lumon 1.5.11

- Remove Stop and Stopping controls from delivery-history rows while preserving Current progress controls, Continue and Delete behavior.
- Keep Current progress status badges in their shared status colors, matching the amber Live badge instead of inheriting muted metadata text.
- Deduplicate Feishu lifecycle notifications by delivery, attempt and event; preserve legacy first-attempt notification receipts.
- Send Delivery Resumed for continuations and include the attempt number in subsequent outcome cards, without changing the single final successful Jira result comment policy.
- Add lifecycle, continuation and badge-color regression coverage and update Dashboard documentation.

Workspace configuration, schedules, existing delivery receipts and worktrees are preserved. This release does not replay notifications for historical attempts or rerun deliveries. Stop controls remain available in Current progress; stopping does not roll back external effects.
