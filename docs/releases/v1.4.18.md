# Lumon v1.4.18

## Auto Delivery notifications

- Remove the verbose Verification field from Feishu lifecycle cards. Verification
  evidence remains available in the persisted run and Dashboard history.
- Record the verified target branch for direct publication, rather than the
  isolated worktree branch. Reject an incorrect branch before saving a completed
  direct-publication receipt. Explicit target overrides and each repository's
  configured branch are supported.
- Clarify the completion command and built-in workflow instructions. Local,
  feature-branch and PR modes continue recording their source branch. Worktree
  isolation and the actual publishing strategy are unchanged.

## Upgrade

Run `lumon update` after the Release is published. Subsequent scheduled Auto
Delivery processes use the new notification and completion behavior. Already sent
Feishu cards and historical receipts are not rewritten or resent.

Workspace configuration, credentials, schedules and automation enablement remain
unchanged.
