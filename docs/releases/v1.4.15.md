# Lumon v1.4.15

## Automation configuration and delivery

- Move Auto Delivery and Auto Scan configuration into Settings, with independent
  Save buttons. Keep the automation pages focused on progress and run history.
- Detect Auto Delivery candidates through bounded, read-only Jira queries using
  the authenticated TWG CLI. Empty queries, previously handled cards and failed
  detection do not start Codex. Technical Plans remain optional.
- Configure publication separately: local-only delivery, a pushed feature
  branch, a feature branch with a PR, or a normal push to the target branch.
  Default to local-only delivery; never implicitly merge, force-push or deploy.
- Package the built-in Auto Scan and Auto Delivery workflows as separate
  Markdown documents, outside the Dashboard. Use the saved lookback setting as
  the only Auto Scan review window and retain editable Workspace hook prompts.

## Dashboard

- Integrate scheduled execution into the selected Workflow panel, above the
  Markdown content, and remove the redundant schedule-status badge.
- Add a Langfuse trace link to Agent conversation history when a sampled trace
  has a valid inspection URL. Keep older databases readable and show no invented
  links for historical records without a stored URL.

## Upgrade

After publication, run `lumon update` and restart the Dashboard to load the new
API and UI. Restart the Agent after its current conversations finish to record
trace links for new conversations. Scheduled jobs use the updated package on
their next invocation; do not reload LaunchAgents or interrupt active jobs.

Existing Workspace data, hook prompts, credentials and schedules remain
unchanged. Auto Delivery stays paused if it was paused before upgrading. Older
profiles default to local-only delivery and must configure a Jira site and
trigger JQL before enabling Auto Delivery. Delivery publication still requires
the appropriate repository access and read-back verification; this release does
not automatically retry blocked cards or publish existing local work.
