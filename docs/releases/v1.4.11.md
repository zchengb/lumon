# Lumon v1.4.11

## Dashboard

- Show saved Workflow schedules in the Overview Automation panel alongside
  Auto Delivery and Auto Scan, using the same row styling and keyboard controls.
- Display each Workflow's name, effective enabled/disabled state and cron
  expression. Clicking a row opens that Workflow's schedule settings.
- Refresh saved schedules when returning to Overview and keep schedule data
  isolated to the selected Workspace.
- Keep saved disabled schedules visible. Omit Workflows without a saved schedule,
  deleted Workflows and invalid Markdown files. A disabled Workflow never appears
  enabled even if its saved schedule flag remains set.
- Handle a Workflow disappearing before navigation without making the document
  list unusable, and discard outdated loads after switching Workspaces.

## Upgrade

After the GitHub Release is published, run `lumon update` and restart the Dashboard
process to load the new API and bundled frontend. Agent does not need restarting
for this Dashboard-only change. Workspace data, credentials, model preferences
and scheduled Scan, Delivery and Workflow jobs remain unchanged.

The Automation panel shows saved configuration, not launchd runtime health.
Viewing or opening a Workflow schedule never installs, reloads or starts a job.
