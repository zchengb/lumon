# Lumon 1.5.19

- Connect selected GitHub repositories through the GitHub CLI's existing login. Workspace onboarding and the Dashboard can select repositories, branches and their Auto Scan/Auto Delivery scope without immediately cloning them.
- Give Agent current repository context through scoped GitHub MCP reads. Keep credentials out of Workspace configuration and provide local Git authentication without changing global Git settings.
- Prepare isolated worktrees from freshly fetched branches for Auto Scan and Auto Delivery. Preserve existing checkouts and task worktrees; report unavailable repositories or incomplete history rather than treating stale code as current.
- Preserve existing Workspace registrations. Repositories can be connected to GitHub MCP explicitly from the Overview after upgrading.

GitHub MCP integration requires an authenticated GitHub CLI. Agent shell access is not restricted by the MCP repository scope, and automatic Workflows are not run as part of the upgrade.
