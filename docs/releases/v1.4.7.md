# Lumon v1.4.7

## Dashboard

- Add a dynamic Codex model picker and refresh action through
  `GET /api/agent/models`. Model and reasoning choices come from the installed
  Codex CLI's catalog, without starting an Agent task. Failed refreshes or
  missing catalog entries preserve the current selection. The default remains
  GPT-5.6 Luna with `max` reasoning; choosing a new model requires Save.
- Show Workspace-scoped Feishu executions on the Agent page, including source
  tags, resolved group/user names, Markdown output, duration, filters and
  on-demand input/output expansion. Internal prompts and provider diagnostics
  are not exposed.
- Move global Agent and Langfuse settings to Settings while retaining
  Workspace-specific Webhook configuration and unsaved-change protection.
- Use consistent graphite focus styling and remove redundant Settings labels.

## Auto Scan

- Reconcile abandoned `running` records only when the Workspace scan lock is
  free. Preserve existing findings and reports, and leave active scans alone.
- Record handled interruption/cancellation as failure. Recovery does not
  restart scans, execute completion hooks, send notifications or reload jobs.

## Upgrade

After the GitHub Release is published, run `lumon update`. Reload the Dashboard
process to load its new API and refresh the browser to load the bundled UI.
Do not unload scheduled Scan or Workflow jobs to refresh the Dashboard.
Workspace data, schedules, credentials and saved model preferences remain
unchanged. Model availability depends on the local Codex version and
account/provider configuration; Lumon does not upgrade Codex automatically.
