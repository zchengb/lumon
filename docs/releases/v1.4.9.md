# Lumon v1.4.9

## Dashboard

- Move the Agent and Langfuse Save buttons inside their respective Settings
  panels. Remove the shared Save button below both panels.
- Save only the selected panel's edits while preserving unsaved fields and
  credentials in the other panel. The existing settings API remains compatible.
- Show each panel's own unsaved indicator, preserve drafts after failed saves,
  and disable overlapping saves while an update is pending. Navigation continues
  to warn while either panel has unsaved changes.

## Upgrade

After the GitHub Release is published, run `lumon update`. Reload only the
Dashboard process and refresh its browser tab to load the new UI. Workspace
data, credentials, saved model preferences, and scheduled Scan and Workflow
jobs remain unchanged. This UI-only change does not require restarting Agent
or upgrading Codex.
