# Lumon v1.4.19

## Live Agent steering

- Send follow-up messages in the same private conversation or group Thread to
  Codex's active turn through the native app-server `turn/steer` protocol. Keep
  conversations isolated and acknowledge an input only after Codex accepts it.
- Interrupt explicit stop or publication-hold instructions, including
  `先不要 commit／push` and `/pause`, before continuing with a read-only,
  network-disabled local shell sandbox. Persist the hold across restarts;
  only explicit `/resume` restores the original execution permissions.
- Preserve messages arriving during preparation or turn completion, prioritize
  safety instructions, and stop owned tool processes when interruption cannot
  be confirmed. Never reuse an interrupted turn's final reply.

## Upgrade and boundaries

Run `lumon update` after the Release is published, then restart Agent to load
the new conversational execution adapter. Existing Codex sessions are resumed;
Workspace configuration, credentials, schedules and automation enablement remain
unchanged. Scheduled Auto Scan and Auto Delivery continue using their existing
execution path and are not controlled by conversation steering.

Group messages still require an explicit @Agent mention. Steering cannot undo
already completed or remotely dispatched operations, stop processes that escaped
the owned process group, or revoke remote MCP permissions. Use `/pause` for an
unambiguous hold; arbitrary natural-language restrictions cannot all be detected.
