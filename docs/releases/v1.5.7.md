# Lumon 1.5.7

- Show recorded verification-to-development returns as a same-run rework loop on Auto Delivery's Current progress panel and run inspections.
- Display a rework count, the active correction/re-verification step, and expandable timestamped rework history in English, Simplified Chinese and Traditional Chinese.
- Distinguish an ongoing rework loop from terminal failure or blocking. Command failures alone do not create a rework cycle, and finished runs stop animating.
- Cover repeated phase updates, command noise, live refresh, multiple loops, historical inspection and terminal states.

This is a Dashboard-only change using retained phase events, not a lifetime retry counter or an automatic retry mechanism. Delivery execution, Jira comments, Workspace configuration and schedules are unchanged.
