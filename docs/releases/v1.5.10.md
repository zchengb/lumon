# Lumon 1.5.10

- Continue blocked, failed or stopped Auto Deliveries from Dashboard or CLI without deleting receipts or worktrees. Preserve attempt history, Agent sessions and checkpoints; refresh instructions and revalidate changed source before continuing.
- Stop managed deliveries from Dashboard or CLI. Show Stopping until the owning worker has cancelled and reaped its Agent process tree, then retain the work as Stopped.
- Resume eligible deliveries through the existing Jira polling schedule when a new post-terminal status transition returns the card to the configured JQL entry conditions. Require complete history and prevent reuse of the same transition; never automatically reopen completed deliveries.
- Require a single final successful Jira result comment per logical delivery, with concise results and embedded evidence. Keep intermediate, blocked, failed and stopped outcomes local, and reconcile existing comments before writing.
- Add attempt-aware Dashboard controls and API validation, process cancellation coverage, durable checkpoints and regression tests.

Workspace configuration, registered checkouts and existing receipts are preserved. Legacy executions without stop support must be stopped through their owning worker. Stop does not roll back external effects or guarantee cleanup of detached or remote jobs. Jira comment discipline is an Agent workflow contract, not a restriction on arbitrary Jira API access.
