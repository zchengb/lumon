# Lumon 1.5.5

- Recheck tracked Auto Scan issues against the configured repository branch, independently of the new-change lookback window. Record the commit and detailed evidence separately from the original discovery receipt.
- Update issue history to resolved or reopened only from explicit recheck outcomes. Missing, stale, conflicting or wrong-branch assessments remain unverified; ignored issues stay ignored.
- Refresh Auto Scan history while a known scan is running and the page is visible, without overlapping requests.
- Keep Auto Delivery Current progress focused on the newest running Story, or the latest actual delivery when none is running. Scheduler checks and historical inspections no longer replace it.
- Keep historical execution details in their respective sections, and remove the narrative summary beneath the Current progress stages.

Historical issue verification remains an Agent-led, read-only code review, not independent runtime testing. Existing scan receipts, reports, Workspace configuration and schedules are preserved; no scan or delivery is triggered by this release.
