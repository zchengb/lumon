# Lumon v1.4.17

## Dashboard settings

- Remove the Auto Delivery introductory description from Settings.
- Move Auto Scan overview, lookback and schedule guidance into label-adjacent
  question-mark tooltip bubbles, hidden until clicked.
- Move Agent configuration application rules and Langfuse guidance into the same
  title-adjacent tooltip bubbles. Keep model loading, availability and failure
  messages visible.
- Reuse the existing floating help behavior: opening guidance does not shift the
  form; keyboard focus, Escape, outside dismissal and viewport bounds remain
  supported. Saving behavior and configuration values are unchanged.

## Upgrade

Run `lumon update` after the Release is published, then restart the Dashboard to
load the new UI. The Agent does not need restarting for this UI-only change.

Workspace configuration, credentials, schedules and paused automation states
remain unchanged.
